# Security Policy

## Nature of This Repository
This repository contains YARA rules and decompiled code snippets for **defensive malware research**. It does **not** distribute runnable malware or exploit tooling.

## Reporting Abuse or Concerns
If you believe any content here is being misused or violates policy, please open an issue (do not attach binaries) or contact the maintainer directly. Third-party abuse inquiries are welcome and will be addressed promptly.

## Safe Handling
All decompiled samples are for static analysis only. Do not execute them outside an isolated, authorized laboratory environment.
